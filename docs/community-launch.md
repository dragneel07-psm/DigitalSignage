# Community launch kit

These are drafts for the maintainer to share where project announcements are
welcome. No third-party community posts or outreach have been sent automatically.

## Short post

I maintain DigitalSignage, an MIT-licensed Django noticeboard with Nepali
interfaces. It displays notices, citizen charters, media, and scrolling messages
on existing TVs and monitors. There is now an isolated local demo with fictional
data, plus contributor tasks for documentation, localization, testing, and
accessibility. I would appreciate feedback from school/municipal IT staff and
Python developers: can you get the demo running, and what would make it useful?

Repository: https://github.com/dragneel07-psm/DigitalSignage
Demo guide: https://github.com/dragneel07-psm/DigitalSignage/blob/master/docs/try-demo.md
Contribute: https://github.com/dragneel07-psm/DigitalSignage/contribute
Questions: https://github.com/dragneel07-psm/DigitalSignage/discussions

## First month

- Week 1: Test setup on a second computer; fix the first confusing step.
- Week 2: Invite a few relevant testers individually, with permission. Ask for
  installation feedback rather than stars.
- Week 3: Help a new contributor complete one small issue; credit their work.
- Week 4: Publish a release only after tests pass, with changes and limitations.

Aim for three genuine trials and one outside contribution. These are targets,
not current adoption claims. Record only voluntary, verifiable feedback. Resolve
the previously reported GitHub Actions account lock and rerun CI.
